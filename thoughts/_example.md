This is an example post. Files starting with _ are drafts and never published,
so this one stays private. Copy it, rename the copy, and write.

NAMING
  Name the file with the date first, then the headline:
      2026-11-26 Why I like chess.md
  The date sets the order on the Thoughts page (newest on top).
  The rest of the name becomes the headline.

  If the headline needs characters a file name can't have (like ? or :),
  put it on the first line instead, starting with "# ", and that wins:
      # What is a qubit, really?

  To keep something as a draft, start the file name with _ .

WRITING
  Plain text works. Blank lines separate paragraphs.
  Markdown also works for a little formatting:

  ## A subheading
  *italic*, **bold**, [a link](https://example.com)
  - a bulleted
  - list
  > a quote
  `code`, and ``` on its own line before and after a code block

IMAGES
  Put the image in this thoughts/ folder and write:  ![short description](photo.jpg)
